Wi-Fi HaLow OpenWrt Bridge - Change Log
========================================

1.2.3  2026-10-22
  Fix: lint.sh now lists openwrt/halow-ap.init explicitly.  The
       openwrt/*.sh glob does not match .init files, so the procd init
       script had been silently skipped since the previous revision.
       This was a lint-gate regression, not a lint-pass.
  Fix: README malformed AOSP URL containing a space.
  Docs: README section 10 sharpens the cdc_ncm mechanism with the
        FLAG_ETHER | FLAG_POINTTOPOINT and (net->dev_addr[0] & 0x02)
        check from drivers/net/usb/cdc_ncm.c.
  Docs: README section 9 states the respawn 3600 5 5 rationale
        explicitly: bounded retries surface config errors instead of
        masking them, unlike hostapd's own 3600 1 0.
  Docs: README references now include the cdc_ncm commit, the AOSP
        Connectivity CL, and the BusyBox flock commit.

1.2.2  2026-10-22
  Fix: set-global-mac.sh and README state that the globally unique MAC
       bit drives ethN naming (cdc_ncm.c); renaming is the fallback.
  Fix: hostapd_s1g.conf adds eapol_key_index_workaround=0 and
       own_ip_addr=127.0.0.1 (Gateworks S1G examples).
  Fix: start-ap.sh uses flock single-instance guard.
  Fix: install.sh verifies hostapd_s1g presence and chmods the socket dir.
  Fix: lint.sh scopes SC2034 to halow-ap.init only.

1.2.1  2026-10-22
  Fix: placeholder PSK rejected, LICENSE pointer, push gate in repo.

1.2.0  2026-10-22
  Fix: lint gate, uci-defaults radio guard, setup-relayd SC2140.

1.1.0  2026-10-22
  Add: GPL-2.0, install.sh, GHSA completeness, thermal warning.

1.0.0  2026-10-21
  First stable release.
