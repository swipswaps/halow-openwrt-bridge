Wi-Fi HaLow OpenWrt Bridge - Change Log
========================================

1.2.5  2026-10-22
  Fix: setup-relayd.sh writes network as a UCI list (uci set + uci
       add_list), not a space-separated string.  relayd validates the
       option as list(string) and reads it with config_get; the string
       form left relayd with a single bogus network name.
  Fix: setup-relayd.sh runs /etc/init.d/network reload after commit so
       netifd instantiates the relay interface before relayd starts.
  Fix: setup-relayd.sh installs relayd with apk when opkg is absent.
  Docs: README section 8 documents the UCI list semantics and the
        network reload requirement; references cite relayd's
        network:list(string) validation.

  Docs: thermal thresholds 90/85 C from Application Note 56.
