Wi-Fi HaLow OpenWrt Bridge - Change Log
========================================

1.2.2  2026-10-22
  Fix: set-global-mac.sh and README now state that the globally unique
       MAC bit is the primary mechanism for ethN naming (cdc_ncm.c);
       renaming is the fallback.  The previous round incorrectly said
       the bit does not affect naming.
  Fix: hostapd_s1g.conf adds eapol_key_index_workaround=0 and
       own_ip_addr=127.0.0.1, both present in every Gateworks S1G
       example.
  Fix: start-ap.sh uses flock on /var/run/halow-ap.lock so two
       invocations cannot race; FORCE=1 still replaces a running AP.
  Fix: install.sh verifies hostapd_s1g is installed and chmods
       /var/run/hostapd 750.
  Fix: lint.sh scopes SC2034 to halow-ap.init only.
  Docs: README section 10 corrects the CDC-NCM mechanism and scopes
        the Android regex claim to pre-U / U+ / V+.
  Docs: README section 12 states that a tag without the fetched
        GPL-2.0 text is non-compliant with §1.

1.2.1  2026-10-22
  Fix: placeholder PSK rejected, set-global-mac rename, LICENSE pointer.

1.2.0  2026-10-22
  Fix: lint gate, uci-defaults radio guard, setup-relayd SC2140.

1.1.0  2026-10-22
  Add: GPL-2.0, install.sh, GHSA completeness, thermal warning.

1.0.0  2026-10-21
  First stable release.
